# Learning Mode — Emergent Noise as a Research Laboratory

Emergent Noise is also an **interactive learning environment** for exploring
complex systems science, artificial life, information theory, morphogenesis and
self-organising simulation.

## What the Learning Layer provides

Each experiment preset includes a **LearningModule** containing:

- **What am I seeing?** — Intuitive explanation of the dynamics with scientific caution
- **Parameter notes** — What each parameter does mathematically and what happens when you change it
- **Mathematical background** — Key equations and concepts in plain language
- **Guided experiments** — 2–5 step-by-step mini-experiments with observation questions
- **Research Trail** — Curated books, papers, courses, podcasts and projects

## Learning Mode in the dashboard

Open the **Lernen & Theorie** tab (Tab 4). After selecting a preset in the sidebar:

1. The **Learning Mode panel** activates automatically
2. Navigate the five inner tabs: `What am I seeing?` / `Parameters` / `Mathematics` / `Guided Experiments` / `Research Trail`
3. The **Research Trail** tab has level and type filters (beginner → research, book → podcast)
4. The **classic depth levels** (Einstieg / Mittelstufe / Forschungsfront) remain accessible via expander

## Scientific caution

All descriptions use hedged language. This simulator provides **structural analogues**
of natural phenomena, not accurate biological, physical or cognitive models.
No preset "proves" consciousness, life or a specific physical theory.
